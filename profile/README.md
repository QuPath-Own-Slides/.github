## First Look at QuPath

QuPath is for people who keep slides they own and want one named qupath desk, not mixed untitled tiles. It gives you own slides, an annotation list, and a short path back to a tile view you already keep. It does not replace the rest of your PC. It sits beside the images you already use.

## Inside QuPath

QuPath is a local Windows slide app with a named qupath desk, a short annotation list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside slides you already keep and holds only the tile that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra tiles wait for their own title. QuPath starts with a local profile and does not need a complex account system.
